## Wireshark Command-Line (tshark) Examples

# Export HTTP objects from PCAP
tshark -r CTI_Assignment_Traffic_2025-2026.pcap --export-objects http,/output/directory

# Extract DNS queries to CSV
tshark -r CTI_Assignment_Traffic_2025-2026.pcap -Y "dns.flags.response == 0" -T fields -e frame.time -e ip.src -e dns.qry.name -E header=y -E separator=, > dns_queries.csv

# Extract HTTP requests to CSV
tshark -r CTI_Assignment_Traffic_2025-2026.pcap -Y "http.request" -T fields -e frame.time -e ip.src -e ip.dst -e http.request.method -e http.request.uri -E header=y -E separator=, > http_requests.csv

# Count packets by protocol
tshark -r CTI_Assignment_Traffic_2025-2026.pcap -q -z io,phs

# Extract TLS handshakes
tshark -r CTI_Assignment_Traffic_2025-2026.pcap -Y "tls.handshake" -T fields -e frame.time -e ip.src -e ip.dst -e tls.handshake.type


## Wireshark GUI Operations

# Export C2 payload for VirusTotal analysis
1. Apply filter: ip.addr == 13.201.207.191 && http
2. Locate HTTP 200 OK response from server
3. Right-click packet > Follow > TCP Stream
4. Change "Show and save data as" to "Raw"
5. Click "Save as..." > save as set_agent_payload.html
6. Upload to VirusTotal for malware family attribution

# Export full packet capture to CSV
File > Export Packet Dissections > As CSV
Select all packets or apply filter first

# Create IO Graph for traffic analysis
Statistics > I/O Graph
Add filters for different traffic types to visualize timeline

# View Conversations
Statistics > Conversations > TCP tab
Sort by "Bytes" column to identify largest data transfers

# Protocol Hierarchy
Statistics > Protocol Hierarchy
View breakdown of protocols in capture
